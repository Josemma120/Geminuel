# Legacy — Node.js (Obsoleto)

Este directorio contiene archivos del servidor original en **Node.js**,
reemplazados por la migración a **Python (FastAPI)**.

| Archivo | Estado | Reemplazado por |
|---------|--------|-----------------|
| `server.js` | ❌ Obsoleto | `server.py` (raíz del proyecto) |

## ¿Por qué se conserva?

Se mantiene como referencia histórica. No es necesario para ejecutar el proyecto.

## Para iniciar el proyecto actual (Python)

```bash
# Desde la raíz del proyecto:
python server.py
# o simplemente haz doble clic en start.bat
```
